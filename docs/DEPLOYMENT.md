## 1. 运行前提与交付物

### 1.1 最终用户的电脑

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 1809 及以上 / Windows 11，64 位 |
| 运行时 | WebView2 Runtime（Win11 与已装 Edge 的机器通常自带；缺失时安装微软 Evergreen Runtime，仅安装时需要一次联网） |
| 内存 / 磁盘 | 8GB 内存轻薄本可流畅运行；数据库与最多 7 份备份另需约 50–200MB |
| 网络 | **默认完全不需要网络**。手动录入、导入、备份与台账都离线可用；只有用户主动启用自动抓取并扫码登录后，扫码、登录态校验与名单快照才需要访问 B 站网页接口。无遥测、无第三方统计 |
| 权限 | 普通用户即可，不需要管理员；备份目录必须可写 |
| 显示器 | 建议 ≥1280px 宽屏；1024–1280px 侧栏自动折叠为图标条 |

> 「守村人·粉丝档案」是产品显示名；安装包内部标识仍为 `com.vtuber.fans.admin`，目录名不变，覆盖安装不会丢数据（见 §5.2）。

### 1.2 打包者的电脑

| 依赖 | 版本 / 说明 |
| --- | --- |
| Node.js | ≥ 20（本机实测 v24.14.0 / npm 11.9.0） |
| Rust | stable `x86_64-pc-windows-msvc`（实测 1.100.0） |
| VS Build Tools 2022 | 勾选「C++ 生成工具」+ Windows SDK，提供 `cl.exe` / `link.exe`（实测 19.44） |
| git | 源码仓库 `https://github.com/TankGH/vtuber-fans-admin.git`；数据与密钥不入库 |

新开的 PowerShell 中若 `cargo` 不可用，把 `%USERPROFILE%\.cargo\bin` 加入 PATH；运行 Rust 命令前需加载 `vcvars64.bat`（默认 `C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\VC\Auxiliary\Build\vcvars64.bat`），否则 `link.exe` 与 Windows SDK 库不可用。

### 1.3 交付物

| 内容 | 位置 / 名称 |
| --- | --- |
| 免安装可执行文件 | `release/vtuber-fans-admin.exe`（18,534,912 字节；前端资源已内嵌，有 WebView2 即可双击运行；本地构建输出为 `src-tauri/target/release/vtuber-fans-admin.exe`） |
| NSIS 安装包（当前交付） | `release/守村人·粉丝档案_0.2.0_x64-setup.exe`（4.44 MiB / 4,651,042 字节；本地构建输出为 `src-tauri/target/release/bundle/nsis/`） |

## 2. 从源码构建与打包（分发者）

### 2.1 准备与自检

```powershell
cd d:\workspace\codebuddy\vtuber\vtuber-fans-admin
npm install
npm run typecheck        # TypeScript strict 检查
npm run test             # 前端单测（26 个用例）
```

Rust 侧（在已加载 `vcvars64.bat` 的 MSVC 环境内）：

```powershell
cd src-tauri
cargo check
cargo test               # 19 个用例
```

### 2.2 一键打包

**最简单**：在资源管理器中双击 [`scripts/package-windows.bat`](../scripts/package-windows.bat)。脚本会自动加载 `vcvars64.bat`、把 `%USERPROFILE%\.cargo\bin` 加入 PATH、检查 `node_modules`，然后执行打包；结束后会打印产物路径。

手工执行（需先加载 MSVC 环境）等价命令：

```powershell
cd d:\workspace\codebuddy\vtuber\vtuber-fans-admin
npm run tauri:build
```

该命令会先执行 `npm run build`（`tsc --noEmit && vite build`），再编译 Rust Core 并生成 NSIS 安装包。首次打包需要联网下载 NSIS 与插件工具包（缓存到 `%LOCALAPPDATA%\tauri`），release 编译通常 2–10 分钟；GitHub 下载抖动时报 `timeout: global` 时**重试即可**。

> `tauri.conf.json` 的 `bundle.targets` 当前为 `["nsis"]`。WiX 3 默认代码页 1252 不支持中文产品名（报错 `LGHT0311`），故当前不产出 MSI；恢复方法见 §6。

#### 只想自己双击启动？

不装安装包也可以：直接双击仓库 `release/vtuber-fans-admin.exe`（本地重新构建时该文件输出在 `src-tauri/target/release/`）。Tauri 会把 `dist/` 前端资源编译进这个 exe，只要目标机器有 WebView2 Runtime 就能直接运行，不需要 Node.js、Rust、数据库服务或安装过程。**首次启动会出现两步引导（选备份目录 → 完成）**，之后数据落在 `%APPDATA%\com.vtuber.fans.admin`。适用于本机自用与快速验收；要分发给主播 / 助理仍建议使用 `release/守村人·粉丝档案_0.2.0_x64-setup.exe`（带快捷方式与卸载入口）。

> 若只想要 exe、不想等待安装包生成，可在 MSVC 环境中执行 `cd src-tauri; cargo build --release`（前提是 `dist/` 已由 `npm run build` 生成），产物同样是上面的 exe。

### 2.4 分发约定

- 源码与 `release/` 预构建产物通过 `https://github.com/TankGH/vtuber-fans-admin.git` 分发，也可用 U 盘 / 内网共享等本地方式交付；不依赖 CI、不上传应用商店。粉丝数据、主密钥与备份文件**绝不入库**。
- 建议随包附带版本号、SHA-256 与本文档。首次安装若出现 SmartScreen 提示，是因为安装包未做代码签名；分发者可购买代码签名证书后重签，或在受控环境中确认来源后继续。
- 目标机器不需要安装 Node.js、Rust 或任何数据库服务；WebView2 是唯一运行时依赖。

## 3. 安装与首次启动（使用者）

### 3.1 安装

> 本机自用可跳过安装：直接双击 `src-tauri/target/release/vtuber-fans-admin.exe`（见 §2.2）。下面是分发给他人时的安装流程。

1. 双击 NSIS 安装包 `守村人·粉丝档案_0.2.0_x64-setup.exe`，按向导选择安装目录（默认即可），无需管理员权限。
2. 安装完成后从开始菜单或桌面快捷方式启动「守村人·粉丝档案」。
3. 若提示缺少 WebView2 Runtime，先安装微软 Evergreen Runtime，之后运行不再需要联网。

### 3.2 首启引导（两步）

| 步骤 | 操作 | 说明 |
| --- | --- | --- |
| 1 | 填写「备份目录（绝对路径）」 | 建议选非系统盘且有足够空间的目录，例如 `D:\守村人备份`。留空使用默认 `%USERPROFILE%\Documents\vtuber-fans-admin-backups` |
| 2 | 点击「完成引导」 | 应用创建数据库、DPAPI 主密钥、设置文件，并在后台生成第一份加密备份 |

> 首启引导**不要求登录、不要求联网**：自动抓取默认关闭。之后如需启用，进入「系统设置 → 自动抓取」主动开启并二次确认，再按需扫码登录（见 §4.6）。

### 3.3 应用在哪里存数据

| 内容 | 默认位置 |
| --- | --- |
| 数据目录 | `%APPDATA%\com.vtuber.fans.admin`（由 Tauri `app_data_dir()` 解析，identifier 为 `com.vtuber.fans.admin`） |
| 数据库 | 数据目录下 `fans.db` |
| 主密钥 | 数据目录下 `app.key`（Windows DPAPI 保护，请勿编辑或删除） |
| 配置 | 数据目录下 `settings.json`（含 `syncEnabled` / `roomId` / `snapshotHour` / `reminderDaysAhead`） |
| B 站凭证 | 数据目录下 `bili_session.enc`（仅扫码登录后生成，主密钥加密；不进备份清单与日志） |
| 恢复标记 | 数据目录下 `restore.json`（仅恢复流程中短暂存在） |
| 备份 | 首启引导所选目录，默认 `%USERPROFILE%\Documents\vtuber-fans-admin-backups`，含 `backup-*.enc` 与 `manifest.json` |
| 导出 | 默认写入备份目录（`export-*.enc` 或脱敏 CSV），也可在导出时指定路径 |

界面上可通过**底部状态栏左侧**或**系统设置 → 关于与诊断 / 本地数据位置**查看实际绝对路径；若与表中不同，以界面显示为准（例如目录被策略重定向）。

### 3.4 关窗与托盘

- 默认「关闭主窗口时最小化到托盘」，后台继续守护本地数据；双击托盘图标或选择「显示主窗口」恢复。
- 托盘菜单：`显示主窗口` / `立即备份` / `退出应用`。
- 需要真正退出时请使用托盘菜单的「退出应用」，或到 **系统设置 → 托盘与启动行为** 关闭最小化选项。恢复备份也需要这样完全退出后重启。

## 4. 日常使用

### 4.1 粉丝档案（F1）

1. 左侧「粉丝档案」进入；可按 UID / 昵称搜索，按舰长等级、地址审核状态筛选，勾选「仅看手动锁定」。
2. 点击表格行打开右侧详情：曾用名历史、首次互动、上舰周年、观看纪念日、备注、字段锁定开关。
3. 「新建档案」表单分基础信息 / 敏感信息 / 备注三段；敏感段默认折叠，地址与生日以密文落盘。
4. 生日只显示「月日」，地址只显示「省 · 市 · 区」；点击「查看完整地址（需二次确认）」并勾选确认后才展示完整信息，电话仍打码。该操作不写日志、不联网。
5. 「手动锁定字段」是导入合并的唯一裁决依据：被锁定的昵称 / 生日等不会被导入覆盖。

### 4.2 大航海名单与手动导入（F2）

> 手动导入始终是正式功能，不因自动抓取是否启用而关闭。启用同步后拉取的网页端名单会复用同一套档案合并状态机（手动锁定字段不覆盖、同 UID 保留最早首次互动时间）。

字段规范（CSV 表头，UTF-8，支持 BOM；桌面端另支持 `.xlsx`）：

| 列名 | 含义 | 必填 |
| --- | --- | --- |
| `uid` | B 站 UID，档案唯一标识 | ✅ |
| `nickname` | 当前昵称；空格、`丶`、生僻字原样保留 | ✅ |
| `guard_level` | `1` 总督 / `2` 提督 / `3` 舰长 | |
| `rank` | 榜单排名 | |
| `first_interaction_at` | 首次互动时间；同 UID 重复导入时保留最早值 | |
| `birthday` | 生日（加密存储） | |
| `address` | 地址（加密存储） | |
| `note` | 备注 | |
| `unit_months` | 购买月数，用于核算会员有效期 | |
| `price_yuan` | 金额，用于事件与后续记账归集 | |

四步向导：

1. **选择文件**：点「导入在舰名单」→「选择文件」，或使用 `tests/samples/fans_sample.csv`。
2. **字段映射**：自动识别表头；逐列确认或改选「（不导入）」；可填「快照日期」把本次导入关联到某一天的在舰名单。
3. **冲突预览**：显示总行数、新建 / 合并 / 冲突或跳过数量，并逐行解释原因（如「字段 nickname 已被手动锁定，导入值不会覆盖」「缺少 UID 或昵称，已跳过」）。**此阶段不写入任何数据**。
4. **确认写入**：确认后在单事务内批量写入，失败整体回滚；结果区给出成功数、批次编号与逐行提示。

合并规则：同 UID 保留最早 `first_interaction_at`、追加昵称变更历史、锁定字段不覆盖；成员从快照中消失只标记「疑似到期」，不删除档案、不自动降级。

### 4.3 备份与恢复（F6）

- **自动**：每次启动用 `VACUUM INTO` 生成一致性快照，整体 AES-256-GCM 加密后写入备份目录，`manifest.json` 记录时间、记录数摘要、文件大小与 SHA-256；只保留最近 7 份。
- **立即备份**：页面「立即备份」按钮，结果直接在界面显示（文件名 + 保留策略）。
- **恢复**：列表选择备份 → 勾选二次确认 → 系统先为当前库创建安全备份 → 写入 `restore.json` 标记 → **重启应用** → 启动阶段在打开数据库前替换并校验 → 清除标记。失败时保留当前库与标记，不破坏数据。
- **导出**：`导出脱敏 CSV` 为默认项（仅省市区与月日）；`导出加密库文件` 需二次确认，产物为 `export-*.enc`。

### 4.4 系统设置与主题（F7）

- 三套主题即时切换，无需重启：`守村人深蓝`（默认）/ `晨雾浅色` / `暖霞`；切换只改根元素 CSS 变量。
- 可修改备份目录、关窗最小化到托盘、开机自动启动、隐藏生日年份。
- 「关于与诊断」显示版本、运行模式、上次备份、粉丝数与错误原因速查；「重放首启引导」可重选备份目录。
- 「自动抓取」面板：默认关闭的开关、房间号、每日快照时刻、登录状态、扫码登录入口与立即同步按钮，详见 §4.6。

### 4.5 纪念日提醒（F3）/ 舰礼寄送台账（F4）/ 主播记账本（F5）

**纪念日提醒**

1. 进入「纪念日提醒」，选择提前天数（仅今天 / 3 / 7 / 14 天），汇总卡片列出待处理数量与今天到期数。
2. 每条提醒可复制预设祝福话术、标记已处理 / 撤销、跳转粉丝档案；顶栏角标显示待处理数量。
3. 每日首次启动推送一次 Windows 原生 Toast，最小化到托盘时仍可见。生日只按「月日」计算，2 月 29 日在平年按 2 月 28 日提醒；提醒文案不含年份与地址。
4. 处理标记按「UID + 类型 + 具体日期」记录，跨年自动重置。

**舰礼寄送台账**

1. 「新建寄送批次」：填写名称，从当前在舰名单中勾选成员（默认全选），生成逐条寄送清单。
2. 每条记录可设置寄送状态（待寄送 / 地址待补 / 已寄送 / 地址无效）、填写快递单号、审核地址状态；审核结果会同步回粉丝档案。
3. 完整地址需二次确认，电话始终打码；该操作不写日志、不联网。
4. 「导出脱敏清单」需二次确认，内容只有 UID、昵称、等级、省市区掩码与物流单号，不含收件人、电话与门牌号。

**主播记账本**

1. 「新增账目」录入收入 / 支出、分类、金额、日期、备注，可关联舰礼寄送批次。
2. 「归集大航海收入」把导入的购买 / 续费事件按事件 ID 转成收入账目，重复点击不会重复计入。
3. 月度收支趋势图与净额汇总实时计算；删除账目需二次确认。

### 4.6 自动抓取与扫码登录（用户可选）

1. **默认关闭**：安装后不会发起任何外部请求，手动导入不受影响。
2. **主动启用**：「系统设置 → 自动抓取」打开开关，阅读确认框后点击「确认启用」。关闭时不会再有任何外部请求。
3. **填写配置**：直播间房间号（纯数字）与每日快照时刻（0–23 点整点），点击「保存同步设置」。仅写入本机 `settings.json`。
4. **按需扫码登录**：点击「扫码登录 B 站」→ 弹窗展示本地生成的二维码 → 用 B 站 App 扫码并在手机上确认。状态会依次显示「等待扫码 / 已扫码待确认 / 登录成功」；二维码约 3 分钟过期，可点「重新生成二维码」。
5. **凭证保存**：登录成功后凭证经本机 DPAPI 主密钥加密写入 `bili_session.enc`，不写入日志、不进入备份清单、不上传任何粉丝数据。「退出登录」可随时清除。
6. **同步名单**：点击「立即同步一次」，或等待设定时刻由后台线程执行每日快照（每天最多尝试一次，当天已有快照则跳过）。同步结果写入 `guard_snapshot` 并复用导入合并状态机，同日重复同步不会产生重复快照。
7. **失败降级**：登录失效提示重新扫码；网络不可达提示检查网络；接口异常提示稍后重试或改用 CSV / Excel 手动导入。界面直接显示中文原因与建议动作，不需要查看日志。

> 这是基于主播自身账号可见数据的**低频网页端快照**，不保证实时；当前不含直播间 WebSocket 实时事件订阅。B 站网页接口若调整，同步会给出可读错误，手动导入仍完整可用。

## 5. 数据、升级与迁移

### 5.1 本地文件清单

见 §3.3。所有文件都不进入 git（`.gitignore` 已排除 `*.db`、`*.key`、备份产物），也不会被同步到任何云端。

### 5.2 升级 / 覆盖安装

- 产品显示名为「守村人·粉丝档案」，Tauri `identifier` 为 `com.vtuber.fans.admin`，因此**数据目录不变**，覆盖安装不会丢数据。
- 升级前建议先点一次「立即备份」，并把整个备份目录复制一份到其它磁盘。
- 升级后首次启动会再生成一份自动备份；若启动异常，用旧版安装包覆盖回退，并按 §4.3 恢复备份。

### 5.3 换电脑 / 重装系统（重要限制）

- 主密钥 `app.key` 由 **Windows DPAPI（CurrentUser 作用域）** 保护，只绑定当前 Windows 用户。换电脑、换 Windows 账户或重装系统后，**只拷贝 `fans.db` 与 `backup-*.enc` 无法解密其中的地址、生日等敏感字段**。
- 当前没有跨用户密钥迁移工具（见 [`ROADMAP.md`](./ROADMAP.md)）。换机前请在原机：
  1. 用「导出脱敏 CSV」保留可核对的档案清单；
  2. 用「导出加密库文件」得到 `export-*.enc`，并确认新机仍在同一 Windows 用户上下文可解密，否则该密文不可用；
  3. 重要地址信息通过受控的线下方式核对后，在新机重新录入（编辑档案时展开敏感信息段填写）。
- 删除 `app.key` 等同于放弃该用户下所有密文敏感字段，请勿手动清理。

### 5.4 误操作回滚

- 恢复前系统自动创建安全备份，界面会给出安全备份编号；需要回退时选择该备份再走一次恢复流程。
- 导入写入失败会整体回滚；导入成功但结果不满意时，只能通过备份恢复，因此**首次批量导入前建议先立即备份**。

### 5.5 隐私边界

日志只记录操作类型、行数与错误码，绝不写入 Cookie、收件人、电话、完整地址、生日或主密钥。Capabilities 仅开放 `dialog` / `notification` / `fs`（限定本地目录）；自动抓取的网络请求由 Rust Core 在后台线程发起，Web 视图本身不获得任意域的网络权限。二维码在本机生成，登录链接不会发给第三方二维码服务。

## 6. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 双击无窗口 / 白屏 | WebView2 Runtime 缺失或损坏 | 安装微软 WebView2 Evergreen Runtime 后重启应用 |
| SmartScreen 提示「未知发布者」 | 安装包未做代码签名 | 核对随包 SHA-256 与来源后继续；分发者可重签 |
| 「备份目录不可写，请重新选择目录」 | 目录不存在、无写权限或指向只读位置 | 系统设置中更换为本地可写目录，改完点「保存设置」 |
| 「文件格式错误」 | CSV 不是 UTF-8、缺少表头，或 xlsx 受密码保护 | 另存为 UTF-8 CSV 并保留表头；参照 `tests/samples/fans_sample.csv` |
| 导入后某些昵称没变 | 字段被手动锁定 | 属预期行为；在档案详情解除锁定后再导入 |
| 「备份校验未通过」 | 备份文件被改动或 `manifest.json` 缺失 | 当前数据不会被改动；选择其它备份，勿手工编辑 manifest |
| 恢复后界面没变化 | 恢复在重启时才生效 | 完全退出应用（托盘 → 退出应用）后重新启动 |
| 关窗后以为程序退出了 | 默认最小化到托盘 | 托盘菜单「退出应用」，或在设置中关闭该选项 |
| 「自动抓取」开关默认关闭 | 设计如此：由用户主动决定是否启用 | 需要时到「系统设置 → 自动抓取」开启并二次确认，再按需扫码登录 |
| 扫码后一直显示「等待扫码」 | 二维码过期或未在手机上点确认 | 手机确认登录；过期则点「重新生成二维码」 |
| 同步提示「登录态已失效」 | B 站凭证过期 | 重新扫码登录；期间可继续手动导入 |
| 同步提示「无法连接 B 站」/「接口返回异常」 | 网络抖动或网页接口变更 | 检查网络后重试；仍失败则使用 CSV / Excel 手动导入，手动通道不受影响 |
| 打包报 `LGHT0311 ... code page '1252'` | WiX 3 不支持中文产品名 | 当前已把 `bundle.targets` 设为 `["nsis"]`；如需 MSI，自定义 WiX 本地化文件把 `TauriCodepage` 设为 936，或临时改用 ASCII 产品名 |
| 打包卡在 `Downloading .../nsis-3.13.zip` 并报 `timeout: global` | GitHub 下载抖动 | 重新执行 `npm run tauri:build`；工具会缓存到 `%LOCALAPPDATA%\tauri`，也可手动下载该 zip 解压到 `%LOCALAPPDATA%\tauri\NSIS` 后重试 |

> 界面上的错误提示都是中文可读文案并附带建议动作，不需要查看日志文件。

## 7. 卸载与清理

1. 通过「设置 → 应用 → 安装的应用」卸载「守村人·粉丝档案」。
2. 卸载**不会自动删除**数据目录与备份目录，避免误删档案。需要彻底清理时，手动删除：
   - `%APPDATA%\com.vtuber.fans.admin`
   - 首启时选择的备份目录（默认 `%USERPROFILE%\Documents\vtuber-fans-admin-backups`）
3. 删除前请确认已导出需要的脱敏 CSV，并了解 §5.3 的 DPAPI 限制：**密钥删除后密文敏感字段不可恢复**。
